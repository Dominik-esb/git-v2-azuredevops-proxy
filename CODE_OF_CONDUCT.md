# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive. Harassment and personal attacks are not
tolerated in issues, pull requests or any other project space.

Report unacceptable behaviour privately to the maintainer,
[@Dominik-esb](https://github.com/Dominik-esb), through a
[private security advisory](https://github.com/Dominik-esb/git-v2-azuredevops-proxy/security/advisories/new)
or by contacting them on GitHub. All reports are reviewed and handled confidentially.
